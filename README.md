# Manufacturing Production & Rejection Analysis

## Overview
Analyzed manufacturing production data to identify factors contributing to product rejection and operational inefficiencies. Built interactive dashboards and performed SQL analysis to generate actionable business insights.

## Tools Used
- SQL
- Power BI
- Tableau
- Excel

## Key Analysis
- Employee-wise rejection analysis
- Machine-wise rejection analysis
- Department-wise performance analysis
- Production trend analysis
- Quality control monitoring

## Key Insights
- Woven Labels department had the highest rejection quantity.
- A small number of employees contributed disproportionately to rejections.
- Certain machines consistently produced higher rejection rates.
- Rejection spikes were observed during specific production periods.

## Recommendations
- Improve employee quality training.
- Schedule preventive machine maintenance.
- Strengthen quality checks in high-rejection departments.
